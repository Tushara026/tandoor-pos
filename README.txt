TANDOOR & CO. POS — PHONE APP

QUICK START:
1. Open index.html in Chrome on your phone.
2. The app works with local browser storage, so menu and bills persist on the device.
3. Use the browser menu -> Add to Home screen if your browser offers it.
4. For a true installable PWA/offline service-worker version, host this folder on HTTPS.

FEATURES:
- Menu categories and search
- Add/quantity/remove
- CGST 2.5% + SGST 2.5%
- Discount by amount or percentage
- Cash / UPI / Card
- Print receipt / Save as PDF
- Bill numbering
- Sales history
- Restaurant/GSTIN settings
- Add/edit/delete menu items
- Mobile-first layout
